Meu Primeiro Servidor HTTP

Atividade prática introdutória utilizando o IIS no Windows para compreender a comunicação entre navegador, protocolo HTTP e servidor Web.

HTTP • IIS • Windows • Servidor Web

🎯 Objetivo

Compreender, de forma prática, como funciona o acesso a um servidor Web através do protocolo HTTP, utilizando o IIS (Internet Information Services) no Windows.

Navegador → HTTP → IIS → Arquivo HTML → Resposta HTTP → Navegador

🖥️ Ambiente necessário

  • Windows 10 ou Windows 11
  • IIS (Internet Information Services)
  • Microsoft Edge, Google Chrome ou Firefox
  • Bloco de Notas ou Visual Studio Code

1. Preparação do servidor

Verifique se o IIS está instalado no Windows.

Acesse: Painel de Controle → Programas → Ativar ou desativar recursos do Windows

Localize e ative:

Internet Information Services

Após a instalação, abra o navegador e acesse:

http://localhost
Resultado esperado: deverá aparecer a página padrão do IIS.
Registro: faça uma captura de tela da página padrão do IIS.

2. Criando a primeira página Web

A pasta padrão utilizada pelo IIS para publicação de páginas Web é:

C:\inetpub\wwwroot

Crie nessa pasta um arquivo chamado:

index.html

Utilize o conteúdo abaixo:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Meu Primeiro Servidor HTTP</title>
</head>
<body>
    <h1>Meu Primeiro Servidor HTTP</h1>

    <p>Servidor: IIS</p>
    <p>Protocolo: HTTP</p>
    <p>Sistema operacional: Windows</p>
    <p>Aluno: SEU NOME</p>
</body>
</html>

Salve o arquivo em:

C:\inetpub\wwwroot\index.html

3. Primeiro acesso HTTP

Acesse:

http://localhost

Depois acesse:

http://127.0.0.1

Questão

Por que os dois endereços apresentam a mesma página?

5. Criando uma segunda página

Crie o arquivo:

sobre.html

Na pasta:

C:\inetpub\wwwroot

Utilize, por exemplo:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Sobre o Aluno</title>
</head>
<body>
    <h1>Sobre o Aluno</h1>

    <p><strong>Nome:</strong> SEU NOME</p>
    <p><strong>Curso:</strong> SEU CURSO</p>
    <p><strong>Disciplina:</strong> Administração de Sistemas Proprietários</p>
    <p><strong>Tema:</strong> HTTP</p>
</body>
</html>

Acesse:

http://localhost/sobre.html
Questão: Como o IIS conseguiu localizar e apresentar o arquivo?

6. Observando uma requisição HTTP

Abra http://localhost e pressione F12 para abrir as ferramentas de desenvolvedor.

Acesse a aba:

Network / Rede

Recarregue a página e localize a requisição relacionada ao arquivo index.html.

Observe:

Request URL
Request Method
Status Code
Content-Type
Você deverá encontrar informações semelhantes a: 
Request Method: GET
Status Code: 200
Content-Type: text/html

7. Entendendo a requisição

NAVEGADOR
    │
    │ GET /index.html HTTP/1.1
    ▼
   IIS
    │
    │ Localiza index.html
    ▼
    │ HTTP/1.1 200 OK
    │ Content-Type: text/html
    ▼
NAVEGADOR

GET

Método HTTP utilizado para solicitar um recurso ao servidor.

200 OK

Indica que a solicitação foi processada com sucesso.

Content-Type: text/html

Indica que o conteúdo retornado pelo servidor é uma página HTML.

8. Provocando um erro 404

Acesse:

http://localhost/naoexiste.html

Observe o resultado. O servidor deverá informar que o recurso não foi encontrado.

Código HTTP: 404 — recurso não encontrado.
