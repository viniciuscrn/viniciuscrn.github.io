1. A função print()

A função print() é usada para exibir informações na tela. É uma das primeiras funções que aprendemos em Python, pois nos permite ver o resultado das nossas instruções.

Sintaxe básica

print(valor)

Exemplos

# Exibindo um texto simples
print("Olá, mundo!")

# Exibindo um número
print(42)

# Exibindo múltiplos valores separados por vírgula
print("Minha idade é", 17, "anos.")

# Exibindo o resultado de uma expressão
print(5 + 3)

Saída:

Olá, mundo!
42
Minha idade é 17 anos.
8

Parâmetros úteis

Parâmetro Descrição Exemplo
sep Define o separador entre os valores print("a", "b", sep="-") → a-b
end Define o que aparece no final da linha print("Oi", end="!") → Oi! 
# Usando sep e end
print("Python", "é", "incrível", sep=" | ")
print("Linha 1", end=" ")
print("Linha 2")

Saída:

Python | é | incrível
Linha 1 Linha 2

💡 Dica: O texto passado para o print() entre aspas é chamado de string (cadeia de caracteres). Você pode usar aspas simples '...' ou duplas "...".

Format Strings (f-strings)

Uma f-string é uma forma moderna e prática de montar textos que misturam palavras fixas com valores de variáveis. Basta colocar a letra f antes das aspas e inserir as variáveis entre chaves {} diretamente dentro do texto.

Sintaxe

f"texto {variavel} mais texto"

Comparação: com vírgula vs. f-string

nome = "Carlos"
idade = 17

# Forma tradicional (com vírgula)
print("Olá,", nome, "! Você tem", idade, "anos.")

# Com f-string (mais legível)
print(f"Olá, {nome}! Você tem {idade} anos.")

Ambos produzem a mesma saída, mas a f-string é mais fácil de ler e escrever.

Expressões dentro das chaves

As chaves {} aceitam não só variáveis, mas qualquer expressão Python:

a = 10
b = 3

print(f"A soma de {a} + {b} é {a + b}.")
print(f"O dobro de {a} é {a * 2}.")
print(f"O texto em maiúsculas: {'python'.upper()}")

Saída:

A soma de 10 + 3 é 13.
O dobro de 10 é 20.
O texto em maiúsculas: PYTHON

Formatação de números

As f-strings permitem controlar a exibição de números com especificadores de formato, usando dois-pontos : dentro das chaves.

Especificador Efeito Exemplo Saída
:.2f 2 casas decimais f"{3.14159:.2f}" 3.14
:.0f Sem casas decimais f"{7.9:.0f}" 8
:10 Largura mínima de 10 caracteres f"{'Python':10}" Python
:>10 Alinhado à direita f"{'oi':>10}" oi
:^10 Centralizado f"{'oi':^10}" oi 
preco = 49.9
desconto = 0.15

preco_final = preco * (1 - desconto)

print(f"Preço original:  R$ {preco:.2f}")
print(f"Desconto (15%):  R$ {preco * desconto:.2f}")
print(f"Preço final:     R$ {preco_final:.2f}")

Saída:

Preço original:  R$ 49.90
Desconto (15%):  R$ 7.49
Preço final:     R$ 42.42

Exemplo completo com f-string

nome = input("Qual é o seu nome? ")
nota1 = float(input("Digite a nota 1: "))
nota2 = float(input("Digite a nota 2: "))

media = (nota1 + nota2) / 2

print(f"\nAluno: {nome}")
print(f"Nota 1: {nota1:.1f}  |  Nota 2: {nota2:.1f}")
print(f"Média final: {media:.2f}")

if media >= 7:
    print(f"{nome} está APROVADO(A)! 🎉")
else:
    print(f"{nome} está REPROVADO(A). Média mínima: 7.0")

💡 Dica: O \n dentro da string representa uma quebra de linha — útil para deixar a saída mais organizada.

2. A função input()

A função input() é usada para receber dados digitados pelo usuário durante a execução do programa. O programa “pausa” e aguarda o usuário digitar algo e pressionar Enter.

Sintaxe básica

variavel = input("Mensagem para o usuário: ")

Exemplos

# Pedindo o nome do usuário
nome = input("Digite seu nome: ")
print("Olá,", nome)

# Pedindo dois valores e somando
numero1 = input("Digite o primeiro número: ")
numero2 = input("Digite o segundo número: ")

⚠️ Atenção: O input() sempre retorna uma string (texto), mesmo que o usuário digite um número. Para usar o valor em cálculos, é necessário converter o tipo.

Conversão de tipos com input()

# Convertendo para inteiro com int()
idade = int(input("Digite sua idade: "))
print("Daqui a 5 anos você terá", idade + 5, "anos.")

# Convertendo para número decimal com float()
altura = float(input("Digite sua altura (ex: 1.75): "))
print("Sua altura é", altura, "metros.")

Exemplo completo

nome = input("Qual é o seu nome? ")
idade = int(input("Qual é a sua idade? "))

print("Olá,", nome + "! Você tem", idade, "anos.")
print("Em 10 anos, você terá", idade + 10, "anos.")

3. Tipos de Variáveis

Uma variável é um espaço na memória do computador onde guardamos um valor. Em Python, não precisamos declarar o tipo da variável — ela é definida automaticamente conforme o valor atribuído.

Principais tipos

Tipo Nome em Python Descrição Exemplo
Inteiro int Números inteiros (sem vírgula) 10, -3, 0
Decimal float Números com parte decimal 3.14, -0.5
Texto str Sequência de caracteres "Python", 'Olá'
Booleano bool Verdadeiro ou Falso True, False

Declarando variáveis

# int - número inteiro
quantidade = 10
temperatura = -5

# float - número decimal (use ponto, não vírgula)
preco = 29.90
pi = 3.14159

# str - texto (string)
nome = "Ana"
cidade = 'Recife'

# bool - booleano
aprovado = True
matriculado = False

Verificando o tipo de uma variável

Use a função type() para descobrir o tipo de uma variável:

print(type(10))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("Python"))  # <class 'str'>
print(type(True))      # <class 'bool'>

Conversão entre tipos (casting)

# Convertendo string para int
texto = "25"
numero = int(texto)
print(numero + 5)   # 30

# Convertendo int para float
inteiro = 7
decimal = float(inteiro)
print(decimal)       # 7.0

# Convertendo número para string
idade = 18
mensagem = "Tenho " + str(idade) + " anos."
print(mensagem)      # Tenho 18 anos.

Regras para nomes de variáveis

  • Devem começar com letra ou underscore _
  • Não podem conter espaços (use _ para separar palavras)
  • Não podem ser palavras reservadas do Python (if, for, while, etc.)
  • São case-sensitive: nome e Nome são variáveis diferentes
# ✅ Nomes válidos
nome_aluno = "Carlos"
_valor = 100
notaFinal = 8.5

# ❌ Nomes inválidos
# 1nota = 10       → começa com número
# meu nome = "Ana" → contém espaço
# for = 5          → palavra reservada

4. Operadores Aritméticos

Os operadores aritméticos realizam operações matemáticas entre valores numéricos.

Tabela de operadores

Operador Operação Exemplo Resultado
+ Adição 8 + 3 11
- Subtração 8 - 3 5
* Multiplicação 8 * 3 24
/ Divisão (real) 8 / 3 2.666...
// Divisão inteira 8 // 3 2
% Módulo (resto) 8 % 3 2
** Potenciação 2 ** 8 256

Exemplos práticos

a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333333333333335
print(a // b)  # 3   → só a parte inteira
print(a % b)   # 1   → resto da divisão
print(a ** b)  # 1000 → 10³

Precedência de operadores

A ordem de resolução das operações segue a matemática tradicional:

  1. ** (potenciação)
  2. *, /, //, % (multiplicação e divisão)
  3. +, - (adição e subtração)

Use parênteses para controlar a ordem:

print(2 + 3 * 4)     # 14  → multiplica primeiro
print((2 + 3) * 4)   # 20  → soma primeiro

Exemplo: calculadora simples

a = float(input("Digite o primeiro número: "))
b = float(input("Digite o segundo número: "))

print("Soma:", a + b)
print("Subtração:", a - b)
print("Multiplicação:", a * b)
print("Divisão:", a / b)

5. Operadores de Comparação

Os operadores de comparação comparam dois valores e retornam sempre um resultado booleano: True (verdadeiro) ou False (falso).

Tabela de operadores

Operador Significado Exemplo Resultado
== Igual a 5 == 5 True
!= Diferente de 5 != 3 True
> Maior que 7 > 3 True
< Menor que 2 < 1 False
>= Maior ou igual a 5 >= 5 True
<= Menor ou igual a 4 <= 3 False

⚠️ Atenção: Não confunda = (atribuição) com == (comparação)!
x = 5 → guarda o valor 5 na variável x
x == 5 → verifica se x é igual a 5

Exemplos

x = 10
y = 7

print(x == y)   # False
print(x != y)   # True
print(x > y)    # True
print(x < y)    # False
print(x >= 10)  # True
print(y <= 6)   # False

Comparação com strings

nome = "Ana"

print(nome == "Ana")    # True
print(nome == "ana")    # False → maiúsculas e minúsculas importam!
print(nome != "Maria")  # True

Uso prático com if

Os operadores de comparação são muito usados em estruturas condicionais:

nota = float(input("Digite sua nota: "))

if nota >= 7:
    print("Aprovado!")
else:
    print("Reprovado.")

6. Operadores Lógicos

Os operadores lógicos combinam duas ou mais expressões booleanas e retornam True ou False. São três: not, and e or.

6.1 Operador not (NÃO)

O not inverte o valor lógico de uma expressão.

Expressão Resultado
not True False
not False True 
aprovado = True
print(not aprovado)   # False

chovendo = False
print(not chovendo)   # True

6.2 Operador and (E)

O and retorna True somente se ambas as condições forem verdadeiras.

A B A and B
True True True
True False False
False True False
False False False 
idade = 20
tem_carteira = True

# Só pode dirigir se tiver 18+ E tiver carteira
pode_dirigir = idade >= 18 and tem_carteira
print(pode_dirigir)   # True

nota = 6.5
frequencia = 80

# Aprovado se nota >= 7 E frequência >= 75
aprovado = nota >= 7 and frequencia >= 75
print(aprovado)   # False → nota não satisfaz a condição

6.3 Operador or (OU)

O or retorna True se pelo menos uma das condições for verdadeira.

A B A or B
True True True
True False True
False True True
False False False 
tem_dinheiro = False
tem_cartao = True

# Pode pagar se tiver dinheiro OU cartão
pode_pagar = tem_dinheiro or tem_cartao
print(pode_pagar)   # True

Combinando operadores lógicos

É possível combinar not, and e or em uma mesma expressão. Use parênteses para tornar o código mais claro:

idade = 16
tem_autorizacao = True

# Menor de 18 precisa de autorização para entrar
pode_entrar = idade >= 18 or (idade < 18 and tem_autorizacao)
print(pode_entrar)   # True

Exemplo completo

usuario = input("Digite seu usuário: ")
senha = input("Digite sua senha: ")

usuario_correto = usuario == "admin"
senha_correta = senha == "1234"

if usuario_correto and senha_correta:
    print("Login realizado com sucesso!")
elif not usuario_correto:
    print("Usuário incorreto.")
else:
    print("Senha incorreta.")
